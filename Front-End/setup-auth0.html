Create Auth0 Account & Application

First, you need to create an Auth0 account and application.

Instructions:
  1. Click the button above to open Auth0 signup
  2. Create a free account
  3. Go to Applications → Create Application
  4. Name: "MediaMix Hub", Type: "Single Page Web Applications"
  5. Click "Create"

Configure Application URLs

Allowed Callback URLs: http://localhost:3000/auth/success, http://localhost:5000/api/auth0/callback Allowed Logout URLs: http://localhost:3000/login-backend.html Allowed Web Origins: http://localhost:3000 Allowed Origins (CORS): http://localhost:3000
4
Setup Social Connections

Enable social login providers:

Google OAuth:
  1. Go to Auth0 → Authentication → Social → Google
  2. Toggle "Enable" to ON
  3. Create Google OAuth app at Google Cloud Console
  4. Add redirect URI: https://YOUR-AUTH0-DOMAIN/login/callback
  5. Copy Client ID/Secret to Auth0
GitHub OAuth:
  1. Go to Auth0 → Authentication → Social → GitHub
  2. Toggle "Enable" to ON
  3. Create GitHub OAuth app at GitHub Developer Settings
  4. Add callback URL: https://YOUR-AUTH0-DOMAIN/login/callback
  5. Copy Client ID/Secret to Auth0
