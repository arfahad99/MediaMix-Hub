Setup Instructions

Before testing, make sure you have:

  1. Created an Auth0 account and application
  2. Updated your backend/.env file with Auth0 credentials
  3. Updated Front-End/auth0-config.js with your Auth0 domain and client ID
  4. Configured callback URLs in Auth0 dashboard
  5. Set up social connections (Google, GitHub) in Auth0

Required Environment Variables:

AUTH0_DOMAIN=your-domain.auth0.com
AUTH0_CLIENT_ID=your-client-id
AUTH0_CLIENT_SECRET=your-client-secret
AUTH0_AUDIENCE=https://your-domain.auth0.com/api/v2/
AUTH0_CALLBACK_URL=http://localhost:5000/api/auth0/callback
AUTH0_LOGOUT_URL=http://localhost:3000/login-backend.html
